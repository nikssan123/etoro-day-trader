# Open hypotheses

Patterns the bot has noticed but that **do not yet have the sample size to act on** (n < 10).
Written by the `weekly` cycle. Nothing here may change trading behaviour — this file is a
watchlist for the statistics, not a rulebook.

When a hypothesis reaches n ≥ 10 it graduates to `rules.md` as `provisional`. If the effect
disappears as the sample grows, delete it and note why in the weekly summary. Most hypotheses
should die — that is the point of keeping them separate from rules.

Format:

```
### H-001 — <observation>   [n=N, opened YYYY-MM-DD]
Cohort: <what is being measured>
Current reading: <stats so far, explicitly flagged as underpowered>
Graduates when: n >= 10
```
