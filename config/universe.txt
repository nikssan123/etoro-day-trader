# Tradable universe for the bot, one symbol per line.
#
# Why a curated list rather than screening all 12,193 eToro instruments:
#   - The API's pagination is broken. Requesting 13 pages of 1000 returns only ~995
#     unique instruments; pageNumber barely moves the window. Full-catalog screening
#     is simply not possible.
#   - instrumentTypeID filters are silently ignored and instrumentType cannot be
#     projected, so asset class cannot be filtered server-side.
#   - The unfiltered catalog is dominated by illiquid foreign listings and corrupt
#     rows (monthlyPriceChange values of 2,649,900).
# Exact-symbol lookup IS reliable, so the universe is resolved symbol by symbol.
#
# Edit freely — add or remove symbols and run `bin/etoro universe --refresh`.
# Sections are cosmetic; asset class is assigned in the [crypto] section only.
